# CacheOrchestrator.AspNetCore

ASP.NET Core host integration for CacheOrchestrator: Output Cache policies, client Cache-Control, Admin API, vary materialization, and HTTP-aware domain Fusion helpers.

Depends on **CacheOrchestrator.Core** and **CacheOrchestrator.FusionCache**.
For a single package reference that pulls these together, use the meta package **CacheOrchestrator**.
